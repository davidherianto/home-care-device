# Blood Pressure Monitoring and Electrocardiograph System for Home Care Services Patients Based on the Internet of Things
This project goals to develop a health monitoring system that tracks vital cardiovascular indicators, including blood pressure and electrocardiogram (ECG) data. The system uses Internet of Things (IoT) technology to enable real-time monitoring and secure data storage for both blood pressure and ECG measurements. Users can access and monitor health information through a mobile application.

## A. Project Notes
This project was developed as part of my undergraduate thesis and involved collaboration between two researchers. Overall, the home care device was designed to monitor five health indicators: including blood pressure, electrocardiogram (ECG) signals, oxygen saturation, heart rate, and blood glucose levels. All measurement results can be monitored through a website and mobile application.
- As the first researcher, I was responsible for the development of the blood pressure and electrocardiogram (ECG) monitoring system. I was also responsible for developing the mobile application.

## B. Hardware Components
- MPX5050GP (Pressure Sensor)
- AD8232 Module with Electrode Pads (ECG Sensor)
- Microcontroller ESP32

## C. Software Tools
- Arduino IDE: Arduino IDE was used to program the microcontroller for sensor integration, data processing, and IoT communication.
- Android Studio: Android Studio was used to create the mobile application (Health Monitoring.apk).
- Firebase: Firebase was used to store, manage, and synchronize blood pressure and ECG data for real-time monitoring.
